# Smart Mobility Lab – Casablanca

Projet de fin de semestre – Simulation de trafic intelligent

## 🧠 Objectif
Simuler un trafic routier à Casablanca avec SUMO, collecter les données
via TraCI, les transmettre par MQTT et les visualiser avec InfluxDB + Grafana.

## 🛠️ Technologies
- SUMO + TraCI
- Python
- MQTT (Mosquitto)
- InfluxDB
- Grafana
- Docker
- WSL2

## 🚗 Simulation
- 10 véhicules (léger pour PC étudiant)
- Zone réduite de Casablanca
- Données : vitesse, CO2, position GPS, temps d’attente

## 📊 Visualisation
Tableaux de bord Grafana en temps réel.
